## 四、主动回复（前期治理，已定稿）

**真凶不是 `group_chat_plus`（早禁用），是 `astrbot_plugin_astrbot_enhance_mode` 的 `active_reply`（10% 概率 + AI 二次判断）。**

**按鱼片要求：保留吐槽趣味，只要求分清「在和谁说话」。**

| 键 | 原值 | 新值 |
|---|---|---|
| `active_reply.enable` | true | **true（保持）** |
| `active_reply.possibility` | 0.1 | **0.06** |
| `active_reply.model_choice_prompt` | 234 字 | **817 字（重写）** |

**新 prompt 核心：**

> 这不是判断你想不想说话，是判断**这条消息到底是在跟谁说话**。

**SKIP：** 两三人一问一答 / 讨论链条完整 / @ 了别人 / 私事争执 / 上一条是你在说没人接
**REPLY：** 话题悬空 / 泛话题闲聊 / 有梗可接 / 自言自语式感慨
**倾向：** 群里偶尔冒泡的熟人，10 次开口 2~3 次
