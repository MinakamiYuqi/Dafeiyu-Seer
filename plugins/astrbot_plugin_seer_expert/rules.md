# 魂印 / 技能文本的解析节点

这不是规则真相，而是一份**读词条的检查清单**：按这些节点逐项确认，能确定的就下结论，
不能确定的就问人，问清楚后写进 `facts` 表。

## 一、触发时机（先看这一层）

- 回合开始 / 行动开始 / 出手前 / 命中后 / 受击后 / 被击败时 / 退场时 / 每回合结束时
- 注意区分「自身」「己方」「对手」「全场」——同一句话换主体，效果完全不同

## 二、条件词（决定会不会触发）

| 词 | 需要确认什么 |
|---|---|
| 若 / 当 / 只要 | 条件是否每回合重判，还是入场时一次性判定 |
| 首次 / 每 X 次 / 累计 | 计数是否跨回合、是否跨对手 |
| 最多 / 上限 | 上限是数值还是层数 |
| 无视 | 无视的是防御、抗性、免疫，还是属性 |
| 仅对 / 对 XX 无效 | 是否对 BOSS / PVE 生效 |

## 三、效果类型（决定怎么算）

- **增伤类**：加成是乘算还是加算，是否与其他增伤叠乘
- **减伤类**：先减再算还是算完再减（影响固伤与穿防）
- **免疫类**：免疫伤害、免疫异常、免疫削弱，三者不通用
- **固定伤害**：是否受减伤影响、是否受抗性影响
- **穿防 / 无视防御**：穿的是面板值还是最终伤害
- **先制**：先制等级是否受魂印叠加影响

## 四、叠加与持续

- 能不能叠加、叠几层、叠满需要几回合
- 持续几回合、换宠是否保留、退场是否清除

## 五、常见模糊点（优先确认）

1. 「受到的攻击伤害减少 10%」——是否对固定伤害生效？
2. 「免疫异常状态」——是否包含弱化类？
3. 「先制 +1」——与技能自带先制是否取最高还是相加？
4. 「每回合回复最大体力 1/8」——回合开始还是回合结束？
5. 「对 BOSS 无效」——是整条魂印无效，还是仅某一段无效？

## 六、输出格式（问完人之后写库）

```
topic:   <精灵名>·魂印·<关键词>
content: 触发=<时机>；条件=<…>；效果=<…>；叠加=<…>；PVE=<是/否>；存疑=<…>
```

## 七、伤害计算的默认前提（回答前先说清）

算伤害时**默认按对手抗性点满**，也就是三项抗性都按上限 35% 处理：

| 抗性 | 默认值 | 作用 |
|---|---|---|
| 暴击伤害抗性 | 35% | 暴击那部分伤害再 ×(1-0.35) |
| 固定伤害抗性 | 35% | 固定伤害 ×(1-0.35) |
| 百分比伤害抗性 | 35% | 百分比伤害 ×(1-0.35) |

- 抗性实扣 = floor(伤害量 × 抗性)，余数保留：1 点粉伤过 35% 仍打出 1 点。
- 多段固伤/粉伤必须逐段过抗再相加，不能合并后乘一次抗性。
- 真实伤害不吃任何抗性，不要打折。
- 用户明确说「对面没点抗性」时，才把三项传 0，并在回答里说明这个前提变了。
- 输出里要带上这句前提，免得被当成绝对数值。

## 八、空元行者的讨论顺序（很关键）

1. **先问一件事：「告命」有没有带失力宝石。**
   - 带与不带是两套完全不同的节奏，结论会差很远。
2. 默认前提：**失力宝石空元是空元几种流派里目前环境最好的**。
   - 用户没特别说明时，按「告命 + 失力宝石」这一档来讨论强度与打法。
3. **摆位默认按「失力宝石」那套流派**：二号位叵＝告命（告命诗途，绑失力宝石）、三号位乂＝免控（敕界归元）、四号位卌＝先手（阅世，绑威力宝石）、一号位仐＝150（神忏福音之章）、五号位卪＝第五技能。
   - 资料里的「空元摆位-传统版」是无失力版本，只作参考，不要默认套用。
   - 失力宝石本身只按对手弱化挂一回合减伤，几乎没用；关键是 0 级弱化也能挂，从而触发告命锁切，所以一级就能用。
   - 玩家没说清摆位时，先按失力流派的默认前提给结论，再问一句他实际怎么摆。
4. 算伤害前确认两件事：告命有没有失力宝石、告命在哪个位次；两项都默认按「二号位告命 + 失力宝石」。
5. 再谈配招、对位，不要跳过前面几步直接给结论。

## 九、技能代指怎么认

玩家常用两种方式称呼技能：**按威力**（150 / 130 / 85）与**按效果**（免控 / 先手 / 吸血 / 锁切）。
同一句「150」「先手」在不同精灵身上指的不是同一个技能。

遇到代指时：
1. 先用 seer_pet / seer_moveset 拉该精灵的技能表；
2. 按威力或效果去表里对号，别跨精灵套用；
3. 对不上就问一句「你说的 150 / 先手 是哪个技能全名」。

## 十、给配招建议时的默认框架

玩家没指定时，按这个顺序给五格：**先手 / 强化 / 免控 / 150 大招 / 第五技能**。

1. 先用 `seer_moveset` 拉技能表，按效果对上先手、强化、免控、150 威力大招；
2. 第五技能固定占一格；
3. 有多个候选就说清差异让玩家选，别硬凑；
4. 例外：空元这类已有既定流派（失力宝石流派＝二号告命 / 三号免控敕界归元 / 四号先手阅世 / 一号 150 神忏福音之章 / 五号第五），按流派摆位走。

## 十一、增减伤三步走（不许相减抵扣）

1. **先算增伤**：通用增伤之间相加；额外增伤是独立乘区，与通用相乘。
2. **再算减伤**：通用减伤之间相加；额外减伤独立乘区，
   总减伤 = 1 - (1-通用) × (1-额外)（例 30% 额外 + 10% 通用 = 37%，不是 40%）。
3. **最后相乘**：伤害 = 基础 × 增伤乘区 × (1 - 总减伤)。

禁止把增伤与减伤放在一条式子里相减（例如「增伤 40% − 晨曦减伤 30% = 10%」是错的）。
晨曦一类减伤归到减伤侧，按通用/额外分类后再算。

## 十二、算伤害前的通道清单（照着念一遍）

| 通道 | 有没有 |
|---|---|
| ① 攻击红伤 | 一定会算 |
| ② 固定伤害 | 技能/魂印有没有附固伤 |
| ③ 百分比粉伤 | 有没有按最大体力比例扣血 |
| ④ 真实伤害 | 有没有不吃减伤的 |
| ⑤ 每回合持续 | 吸血、每回合固伤、异常伤害——按回合数累加 |

多回合连招（如「强化接先手」）要**逐回合列**：每回合先结算该回合的吸血/回合效果，再算当回合红伤，最后把各回合相加。只报红伤是最常见的漏项。

工具用法：每回合粉伤用 `percent_segments` 逐段传（如两回合各 1/3 → "0.3333,0.3333"），固伤用 `flat_segments`；每段各自过抗性后再相加。
