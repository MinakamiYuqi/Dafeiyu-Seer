# 配置图 · 收录与备注格式

> 复制下面的模板，把 `<>` 里的内容改掉即可。

---

## 一、收录（要带图）

**模板**

```
收录配置图 <精灵名或ID> [作者:<作者>] [备注:<备注>]
```

**直接可用的例子**

```
收录配置图 艾夏拉 [作者:佑栖] [备注:5级秘咒净灵咒，7级特攻加一天蛇，5级威力灵剑]
```

```
收录配置图 雷伊 [作者:张三] [备注:物攻流，配泰坦刻印]
```

```
收录配置图 70 [作者:老王]
```

> 图片必须和这条指令**放在同一条消息里**一起发出去，分两条发收不到图。

**同一只精灵可以有多套配置，按「作者」区分：**

| 情况 | 结果 |
| --- | --- |
| 新作者 | **新增一套**，之前的保留 |
| 同一个作者再传 | **替换他自己那套**（套数不变） |
| 不写作者 | 用你的群昵称当作者，同样按昵称去重 |

一只精灵收录两套（两个人各发一次）：

```
收录配置图 艾夏拉 [作者:佑栖] [备注:5级秘咒净灵咒，7级特攻加一天蛇，5级威力灵剑]
```

```
收录配置图 艾夏拉 [作者:霜宝] [备注:8级秘咒，双防向]
```

## 二、只改作者/备注（不动图片）

**模板**

```
配置备注 <精灵名或ID> [作者:<作者>] [备注:<备注>]
```

**例子**

```
配置备注 艾夏拉 [作者:佑栖] [备注:改成双防流，换天蛇]
```

```
配置备注 雷伊 [备注:补一句：速度压到 300 以下]
```

只写作者、只写备注、两个都写，都行。

> 一只有多套配置时，**必须带「作者:」指定改哪一套**，否则会提示你从现有几套里选。

---

## 三、替换某一套

对**同一个作者**重新收录一次就是替换他那套：

```
收录配置图 艾夏拉 [作者:佑栖] [备注:换成新配置了]
```

- 旧图会被覆盖，**不保留历史版本**
- 没重新写的作者/备注**保留旧值**（只换图不会把备注弄丢）
- 成功会回 `✅已替换【艾夏拉（3673）】的配置图`
- 首次收录才显示 `✅已收录`

只想改文字、不动图：

```
配置备注 艾夏拉 [备注:只是改个说法]
```

## 四、查询

```
配置图 <精灵名或ID>
```

别名：`配置 艾夏拉`、`艾夏拉配置图`

**只有一套**：直接出图。

**有多套**：先问你「想看哪套」，回序号就发那一张：

```
🧩【艾夏拉】收录了 2 套配置，想看哪套？
1. 佑栖 — 5级秘咒净灵咒，7级特攻加一天蛇，5级威力灵剑
2. 霜宝 — 8级秘咒，双防向

💬 输入序号查看 · 输入 0 退出
```

- 回 `1` / `2` → 发对应的那张图
- **看完一套可以接着回别的序号**，连着看几套都行（每次重新计 60 秒）
- 回 `0` → 退出
- 60 秒不理 → 自动超时退出
- 想跳过提问：`配置图 艾夏拉 2` 直接看第 2 套

> 等待只认**你自己**发的消息，群里别人说话不会被拦。
> 群里跟进时记得还是 @ 机器人（或带唤醒前缀），否则消息到不了 bot。

## 五、写法规则

| 项 | 说明 |
| --- | --- |
| 位置 | **精灵名/ID 必须写在最前面**，后面才是作者、备注 |
| 方括号 | `[ ]`、`【 】`、`〔 〕`、`( )` 可有可无，写了更整齐 |
| 字段名 | `作者` / `来源` 等价；`备注` / `说明` 等价 |
| 分隔符 | 冒号 `:`、全角冒号 `：`、等号 `=` 都行 |
| 不写字段名 | 名字后面的自由文字**整句当备注**，例：`收录配置图 雷伊 这是物攻流` |
| 作者不填 | 自动用**发消息那个人的群昵称**；拿不到昵称就用 UID 后 6 位 |
| 图片限制 | 支持 `png / webp / jpg / jpeg`，单张 ≤ 8 MB |
| 多套 | 同一精灵按作者分套；新作者=新增，同作者=替换他那套 |
| 看第几套 | `配置图 艾夏拉 2`（名字后面跟序号） |
| 一次显示 | 最多 5 套直接连图带字发出来，更多则只列清单+作者备注 |

## 六、容易踩的坑

| 现象 | 原因 | 正确做法 |
| --- | --- | --- |
| `❌未找到匹配的精灵: 艾夏拉[` | 名字和 `[` 连在一起、中间没空格 | `艾夏拉 [作者:...]`，名字后面留个空格更稳 |
| `❌消息里没有图片` | 图是单独一条消息发的 | 文字和图片一起选中发送 |
| `❌匹配到 N 个精灵` | 名字有重名 | 改用精灵 ID（`配置图 70` 里的那个数字） |
| `❌你没有收录配置图的权限` | 不在白名单里 | 发 `/sid` 拿 UID，让管理员加到 `pet_config_uploaders` |
| 备注显示不全 | 备注里出现了 `作者:` / `备注:` 字样 | 换个说法，别在备注正文里写这两个词 |
| 问「想看哪套」半天没人回 | 60 秒超时 | 直接发 `配置图 艾夏拉 1` 指定那套 |

## 七、批量补备注

一只一条，连续发即可，互不影响：

```
配置备注 艾夏拉 [作者:佑栖] [备注:5级秘咒净灵咒，7级特攻加一天蛇，5级威力灵剑]
配置备注 雷伊 [作者:张三] [备注:物攻流]
配置备注 布莱克 [作者:张三] [备注:双防，堆特防]
```

## 八、图片文件也可以手动放

不想走群消息的话，直接把图丢进：

```
<AstrBot 数据目录>/plugin_data/astrbot_plugin_seer_info/pet_configs/
```

文件名 = **精灵 ID**，例如 `70.png`、`4923.webp`。
作者/备注可以写在同名的 `70.json` 里：

```json
{
  "author": "张三",
  "note": "物攻流，配泰坦刻印",
  "uploader": "",
  "updated_at": "2026-10-22 01:30"
}
```

这套旧布局（一只精灵一张图）仍然能读，第一次通过指令收录时会自动迁移成多套结构：

```
pet_configs/70/1.png + 1.json      ← 原来那张，自动搬进来
pet_configs/70/2.jpg + 2.json      ← 新收录的那套
```

不写 json 也能查，只是没有作者/备注。
